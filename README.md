# Locsan — app Android

Este repositorio solo publica las versiones de la app de Locsan (APK firmada y `version.json`).
El codigo fuente es privado.

Para instalar: abre la pestaña **Releases** y descarga la APK mas reciente.
Las tablets que ya tienen la app instalada se actualizan solas: avisan "Hay una nueva actualizacion" y se instala desde ahi.
